# Capture Customer App

Screenshot native belum tersedia/terverifikasi oleh audit ini. Tidak membuat placeholder atau menggunakan screenshot Web sebagai gambar Android. Laporan umum keberhasilan mobile adalah USER-REPORTED, bukan bukti rinci setiap layar.

Gunakan perangkat dengan Expo SDK 57/build yang sesuai dan database demo terisolasi. Login sebelum capture. Ambil Beranda, form booking multiservice/qty, searchable dropdown barber, detail booking, riwayat, dan invoice dummy. Gunakan data sintetis, jangan tampilkan password, reset token, JWT, URL Snap, notifikasi pribadi atau nomor transaksi provider asli. Tidak membuat pembayaran/refund baru untuk memperoleh gambar tanpa otorisasi pengguna.

Simpan JPEG terbaca (lebar sekitar 1080 px, target di bawah 400 KB bila memungkinkan). Catat tanggal/build/perangkat tanpa serial dan bedakan mock dari Sandbox. Tambahkan tautan ke README hanya setelah file nyata tersedia dan ditinjau. Lengkapi bukti yang belum ada tanpa meminta pengguna mengulang semua acceptance.
