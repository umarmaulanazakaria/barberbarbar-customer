# Screenshot Customer Web

Capture hanya dari browser Customer Web aktif menggunakan data sintetis. Simpan bukti viewport desktop dan HP untuk katalog, booking tanpa akun, detail/tracking, pembayaran dan invoice. Jangan menyebut screenshot Web sebagai bukti aplikasi Android Native.

Jangan tampilkan nomor HP asli, kode tracking, cookie, credential, URL/token Snap atau identitas transaksi provider. Gunakan fixture terisolasi dan bedakan mock dengan Sandbox nyata. Jangan membuat transaksi provider hanya untuk memperoleh gambar tanpa izin tambahan. Tambahkan gambar ke README setelah file nyata ditinjau.
